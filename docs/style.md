# Style laws

These are owner-level rules, recorded 2026-11-07 in the Surma chats.
They outrank taste and apply to every file a human or an agent produces
in this repository.

1. **No emoji, anywhere.** ASCII, symbols, and kaomoji only ( .-.
2. **Distinctive, beautiful, tidy.** Repositories are meant to look
   niche and deliberate, not template-flavoured.
3. **Languages.** Minimum: every language of Eurasian countries.
   Target: as many as possible. Mechanism: one source of truth per
   document, translations generated from `translations/`, machine drafts
   marked as machine drafts, native-speaker PRs invited.
4. **Facts discipline.** Hardware claims are `verified` or `unverified`,
   always with a source (chat date, upstream link, local test log).
   Unverified never hardens into fact without a test.
5. **Safety before speed.** Device passports, partition backups, and
   typed confirmations come before any flash, always.

The agent-facing summary of these rules lives in [AGENTS.md](../AGENTS.md).
