# Surma

Surma — мобильная операционная система первого порядка: одно общее
пространство пользователя (`surma-shell`, `surma-apps`, `surma-sensord`)
над несколькими взаимозаменяемыми основаниями — Linux, BSD и (в конце)
загрузочный путь Windows. Цели — телефоны, планшеты и прочие небольшие
устройства, с жёстким бюджетом: рабочий интерфейс в 1 ГБ ОЗУ или меньше.

Проект пишется максимально своим: собственная оболочка, собственный демон
сенсоров, собственный формат портов устройств, собственный конвейер
переводов. Вендорный код используется там, где без него не обойтись
(прошивка модема, подписанные цепочки загрузки), но никогда не
распространяется — он вытягивается из самого устройства при установке.

## Форма

```
        surma-shell / surma-apps / surma-sensord
                          |
     +---------+----------+----------+---------+
     |         |          |          |         |
   [1]       [2]        [3]        [4]        [5]
   linux    linux+bsd    bsd      bsd+linux   windows
```

| # | Ветка      | Идея основания                                                            | Статус   |
|---|-----------|----------------------------------------------------------------------------|----------|
| 1 | linux     | mainline-ориентированный мобильный Linux, в духе postmarketOS             | planned  |
| 2 | linux+bsd | ядро Linux с пространством пользователя BSD, в духе Chimera               | planned  |
| 3 | bsd       | чистый BSD на ноутбуках, серверах, x86-планшетах                          | planned  |
| 4 | bsd+linux | FreeBSD с Linuxulator и LinuxKPI                                          | planned  |
| 5 | windows   | Renegade UEFI + образ Windows ARM64 от пользователя, сверху Surma shell   | research |

Ветка 5 не распространяет образы операционной системы: в репозитории
живут работы над UEFI, ACPI-таблицы, установщик, использующий официальные
источники, и оболочка. Смотрите [лицензирование](docs/licensing.md).

## Законы репозитория

1. Никаких эмодзи, нигде. Только ASCII, символы и каомодзи ( .-.
2. Каждый документ, обращённый к человеку, существует минимум на uk, ru
   и en; остальные языки генерируются через `tools/gen-translations.py`,
   машинные черновики помечаются, правки носителей приветствуются.
3. Факты о железе — либо проверенные, либо помеченные как непроверенные,
   с источником. Ничего посередине.
4. Разрушительные операции с устройствами проходят ворота в таком
   порядке: проверка паспорта, бэкап разделов, текстовое подтверждение
   человека.
