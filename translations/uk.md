# Surma

Surma — мобільна операційна система першого порядку: один спільний
простір користувача (`surma-shell`, `surma-apps`, `surma-sensord`)
над кількома взаємозамінними основами — Linux, BSD і (в кінці)
завантажувальний шлях Windows. Цілі — телефони, планшети та інші
невеликі пристрої, з жорстким бюджетом: робочий інтерфейс у 1 ГБ ОЗУ
або менше.

Проєкт пишеться максимально самотужки: власна оболонка, власний демон
сенсорів, власний формат портів пристроїв, власний конвеєр перекладів.
Вендорний код використовується там, де без нього не обійтися (прошивка
модема, підписані ланцюги завантаження), але ніколи не
розповсюджується — він витягується з самого пристрою під час встановлення.

## Форма

```
        surma-shell / surma-apps / surma-sensord
                          |
     +---------+----------+----------+---------+
     |         |          |          |         |
   [1]       [2]        [3]        [4]        [5]
   linux    linux+bsd    bsd      bsd+linux   windows
```

| # | Гілка      | Ідея основи                                                              | Статус   |
|---|-----------|--------------------------------------------------------------------------|----------|
| 1 | linux     | mainline-орієнтований мобільний Linux, у стилі postmarketOS              | planned  |
| 2 | linux+bsd | ядро Linux із простором користувача BSD, у стилі Chimera                 | planned  |
| 3 | bsd       | чистий BSD на ноутбуках, серверах, x86-планшетах                         | planned  |
| 4 | bsd+linux | FreeBSD з Linuxulator і LinuxKPI                                        | planned  |
| 5 | windows   | Renegade UEFI + образ Windows ARM64 від користувача, зверху Surma shell | research |

Гілка 5 не розповсюджує образи операційної системи: у репозиторії живуть
роботи над UEFI, ACPI-таблиці, встановлювач, що використовує офіційні
джерела, і оболонка. Дивіться [ліцензування](docs/licensing.md).

## Поточний стан

Цей репозиторій — каркас: журнал рішень, нотатки архітектури, паспорти
пристроїв та інструменти безпеки існують; код ОС, що запускається, — ще
ні. Чесний порядок робіт — у [дорожній карті](docs/roadmap.md).

## Закони репозиторію

1. Жодних емодзі, ніде. Тільки ASCII, символи та каомодзі ( .-.
2. Кожен документ, звернений до людини, існує щонайменше uk, ru та en;
   інші мови генеруються через `tools/gen-translations.py`, машинні
   чернетки позначаються, правки носіїв вітаються.
3. Факти про залізо — або перевірені, або позначені як неперевірені, з
   джерелом. Нічого посередині.
4. Руйнівні операції з пристроями проходять ворота в такому порядку:
   перевірка паспорта, бекап розділів, підтвердження людини текстом.
